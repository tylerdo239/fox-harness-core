## 0. Vài từ dùng trong báo cáo

- **Phòng máy (container):** mỗi đoạn chat chạy trong một "phòng máy" nhỏ riêng trên server. Model và Python của chat đó nằm trong phòng này. Phòng tắt thì chat mất kết nối.
- **Kết nối trực tiếp (WebSocket):** đường dây mở liên tục giữa trình duyệt và server, để chữ của model chạy ra từng chút. Dây đứt thì trình duyệt không nhận thêm gì.
- **Thư mục dự án:** thư mục trên server chứa file của dự án. **Mọi đoạn chat trong một dự án làm việc chung trên đúng thư mục này.**
- **Tóm tắt lịch sử (compaction):** khi cuộc trò chuyện dài quá sức nhớ của model (32.000 token), hệ thống tự rút gọn các lượt cũ.
- **Hàm trợ giúp:** các hàm Python viết sẵn cho model.
  - `list_datasets()`: liệt kê file dữ liệu
  - `load_dataset()`: đọc file
  - `profile_dataset()`: tóm tắt file
  - `save_artifact()`: lưu kết quả vào ngăn riêng của chat
  - `history(n)`: xem lại lượt n
- **"Đã xác nhận":** gặp ít nhất 2 lần, hoặc đã chỉ ra được dòng code gây lỗi. **"Gặp 1 lần":** chưa chắc chắn.
