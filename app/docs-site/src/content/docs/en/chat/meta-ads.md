**Meta Ads** mode lets the agent work on **your own** Meta ad accounts: read reports, spot anomalies, find out why an ad
is not delivering, and (when the administrator enables it) create or edit campaigns. It only shows when the server has
Meta Ads enabled.

## Connect your account (once)

1. **Settings** → **Connections** → **Meta** card → **Connect**.
2. A Facebook window opens: sign in with your Facebook (Business) account, pick the businesses / ad accounts to allow,
   and approve.
3. The window closes; the Meta card shows **Connected: <your name>**.

The agent sees only the ad accounts Meta grants you. The token is encrypted and kept on the server only.
**Disconnect** deletes it and revokes the permission at Meta. When the connection expires, the card says
**Connect again**.

## Ask about your ads

Sidebar → **Meta Ads**, then ask as usual, for example:

- "Spend over the last 7 days per campaign — which has the highest CPC?"
- "Did any campaign drop unusually this week?"
- "Why is ad set X not delivering?"

With several ad accounts the agent asks which one. The numbers come straight from Meta.

## Create or edit campaigns

When you ask for a change (create a campaign, ad set or ad, change a budget, turn something on…), the agent **does not
do it right away**: the chat shows a **Confirm a change on Meta** card with what will change.

- **Approve**: the change is sent to Meta and the card says **Done on Meta**. New campaigns, ad sets and ads are always
  created **paused**.
- **Decline**, or no answer within 10 minutes: nothing changes.
- A red **can start spending** line marks a change that turns something on or changes a budget — read it before you
  approve.

Only the owner of the chat can confirm its changes.
