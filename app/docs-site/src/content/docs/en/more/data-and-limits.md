## Who sees your data

- Your chats, projects, files, skills and dashboards **can be opened only by you** in the app.
- Admins manage accounts and the company data sources.

:::caution
Fox Harness is an internal tool. Don't upload data you are not allowed to share.
:::

## Keeping and deleting

| What                      | Details                                                                          |
| ------------------------- | -------------------------------------------------------------------------------- |
| Chat history is kept      | Up to 12 months after it was last used                                           |
| Deleting a chat           | Removes its history, working files and every archived copy; it cannot be undone  |
| Deleting a project        | Also deletes all of the project's chats and files                                |

## Limits

| Limit                 | Value                                          |
| --------------------- | ---------------------------------------------- |
| Chat messages         | 20 per minute                                  |
| File uploads          | 70 MB per file, 10 uploads per minute          |
| Failed logins         | 10 per minute per email                        |
| Login session         | Expires after 1 hour without use               |
| Skills                | 50 per person, content up to 64 KB             |

The exact values can differ depending on how your organisation set it up.
