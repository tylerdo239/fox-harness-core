**I can't find a sign-up button.**
There is no sign-up. Ask an admin to create your account.

**I forgot my password.**
Ask an admin to reset it.

**My project chats aren't in the sidebar.**
That's expected: project chats are on the project's page (Data analysis → the project → Chats tab); Data Studio chats are
inside Data Studio.

**Data Studio says it can't find the data.**
The table you asked about may not be open to you. Ask an admin.

**Where is the Upload file button?**
Only in project chats (Data analysis). Regular chats and Data Studio don't take files.

**I edited a dashboard, went back and lost everything.**
Click **Preview** or **Publish** to save before leaving the builder.

**"Too many messages".**
You sent over 20 messages in a minute. Wait a moment and send it again.

**"This turn stopped at a limit…".**
Each turn has a step and time limit. Send "continue" and the agent carries on from what it already has.

**"Lost connection to the agent".**
Reload the page.
